# خامات السماء (Sky Textures)

ضع هنا ملفات صور السماء الخاصة بالمتاهة. يمكنك استخدام:
1. **صور بانورامية (HDRI/Equirectangular):** صورة واحدة تغطي السماء بالكامل.
2. **صندوق السماء (CubeMap):** 6 صور للجوانب (px, nx, py, ny, pz, nz).

### الملفات المقترحة:
- `sky_bg.jpg` (الخلفية الأساسية)
- `sky_cloudy.jpg` (سماء غائمة)
- `sky_night.png` (سماء ليلية)

سيتم برمجتها لتتغير بناءً على وقت اللعبة أو نوع المرحلة.
