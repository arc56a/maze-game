# مجلد الحركات (Character Animations)

ضع هنا ملفات الحركات الخاصة بالشخصيات. يفضل استخدام صيغة **GLB** أو **FBX**.

### الملفات المطلوبة:
- `idle.glb` (الانتظار/التنفس)
- `walk.glb` (المشي)
- `run.glb` (الجري)
- `jump.glb` (القفز)

### ملاحظة هامة:
يرجى التأكد أن الحركات تم تصديرها بنفس الهيكل العظمي (Skeleton) الخاص بالشخصية الأساسية لضمان عملها بشكل صحيح.
